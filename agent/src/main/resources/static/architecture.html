    How to use the demo

    1. Start the MCP server: ./run-mcp-server.sh
    2. Start the agent app: ./run-agent.sh
    3. Open the chat UI, ask a question, and watch the trace.
    4. Use the Multi-agent tab for the planner and specialist agents.
    5. Click Refresh MCP in the UI to exercise reconnect.
