# Bank overview

Welcome to the demo bank. This knowledge base answers questions about accounts,
cards, payments, fees and security. Customer-specific data (balances, transactions,
spending, income) is never stored here; it is only available through the banking
tools for the signed-in customer.

## Customers

The demo bank has three seeded customers: alice (retail), bob (premium) and carol
(business). Each customer sees only their own accounts, transactions, cards,
conversations and uploaded documents.

## How the assistant works

The banking assistant is a team of agents. A router classifies each question, a
domain agent gathers the facts (bank data comes exclusively from the bank MCP
server, bank policies come from this knowledge base), a writer drafts the answer
and a critic reviews it. The full conversation history is remembered, so follow-up
questions such as "and last month?" or "what about dining?" refer to earlier turns.
